
# Blinkit Sales Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing **Blinkit grocery sales data** using **Power BI** to create an interactive and insightful sales dashboard.  
The dashboard helps understand **sales performance, category-wise contribution, regional trends, and time-based patterns**, enabling data-driven decision-making.

---

## 🎯 Objectives
- Analyze sales performance across products, categories, and regions  
- Identify top-performing product categories  
- Understand customer purchasing trends over time  
- Create a visually interactive dashboard for business insights  

---

## 🗂️ Dataset Information
- Source: Blinkit Grocery Sales Dataset (Excel)
- Records: **5,000+ transactions**
- Key Fields:
  - Product Name
  - Category
  - Sales Amount
  - Quantity Sold
  - Order Date
  - Region

---

## 🛠️ Tools & Technologies Used
- **Power BI**
- **Power Query Editor**
- **DAX (Data Analysis Expressions)**
- **Microsoft Excel**

---

## 🔄 Data Preparation
- Cleaned and transformed raw data using **Power Query**
- Removed null and duplicate values
- Standardized date and numeric formats
- Built a **star schema data model** for efficient analysis

---

## 📊 Dashboard Features
- **KPI Cards**: Total Sales, Total Orders, Average Order Value  
- **Bar Charts**: Category-wise and Region-wise sales  
- **Line Chart**: Monthly sales trend analysis  
- **Pie Chart**: Category contribution to total sales  
- **Slicers**: Dynamic filtering by category and region  

---

## 🔍 Key Insights
- **Beverages and Dairy** emerged as top-performing categories  
- Sales showed a **~15% increase during weekends**  
- Certain regions consistently recorded higher average order values  
- Sales trends revealed seasonal and demand-based patterns  

---

## 📈 Business Impact
The dashboard provides a centralized view of sales performance and can support:
- Inventory planning  
- Category-level decision making  
- Regional sales strategy  
- Performance monitoring through real-time KPIs
